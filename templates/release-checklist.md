# Release Checklist

## Antes da promoção

- [ ] Build concluído com sucesso
- [ ] Unit tests aprovados
- [ ] API tests aprovados
- [ ] Contract tests aprovados
- [ ] Smoke test aprovado
- [ ] Fluxos E2E críticos aprovados
- [ ] Regressão planejada concluída
- [ ] Defeitos críticos tratados
- [ ] Riscos residuais registrados
- [ ] Logs e dashboards revisados
- [ ] Integrações críticas validadas
- [ ] Evidências armazenadas
- [ ] Rollback conhecido e viável

## Após a promoção

- [ ] Health checks aprovados
- [ ] Smoke em produção concluído quando permitido
- [ ] Métricas principais monitoradas
- [ ] Erros/logs anormais verificados
- [ ] Eventos críticos confirmados
- [ ] Comunicação da release realizada
